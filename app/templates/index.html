How it stays safe

This is the part most "AI + database" demos skip. LedgerAsk never gets write access, ever.

Read-only, always

Every query is checked to be a single SELECT statement before it runs, and the database connection itself is opened read-only as a second layer of defense.

Fully auditable

Every question and the exact SQL it produced is logged. You can always see where a number came from — the chat shows it right next to the answer.

Row limits & timeouts

No query can hang the system or dump your whole database into a chat message — hard limits are enforced on every single call.
