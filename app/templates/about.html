About LedgerAsk

LedgerAsk is a demo project showing how an AI assistant can safely answer questions about a company's own sales data — in plain English — without ever being given write access to that data.

Under the hood, the assistant doesn't have free-form database access. It can only call a fixed menu of read-only tools: list tables, describe a table's columns, run a single validated SELECT query, or use a few pre-built business shortcuts like "revenue by month" or "top products." Every query is checked, row-limited, time-limited, and logged.

All data in this demo is synthetic — generated by a reproducible seed script, not a real company's information.

Built by Vento AI

This project was built as a portfolio piece by Vento AI, an independent AI engineering practice focused on practical, safety-conscious AI tooling — RAG systems, voice agents, and assistants like this one that connect language models to real business systems responsibly.
